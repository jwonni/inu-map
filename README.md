# 캠퍼스 한 걸음 · INU Map

인천대학교 송도캠퍼스의 건물·호실과 오늘 열리는 행사를 찾는 웹 지도입니다. HTML, CSS, JavaScript로 구현했으며 별도 설치나 빌드 없이 실행할 수 있습니다.

## 실행

저장소를 내려받은 뒤 **[campus-map/index.html](campus-map/index.html)**을 브라우저에서 여세요. 제출 결과물을 확인하는 기본 시작 파일입니다.

VS Code의 Live Server로 실행하거나, 저장소 루트에서 아래 명령으로 로컬 서버를 실행해도 됩니다.

```bash
python3 -m http.server 8000
```

이후 `http://localhost:8000/campus-map/`에 접속합니다.

## 주요 기능

- **지도**: 건물·호실 검색, 층별 실내 배치, 지도 확대·이동, 전체 건물 Quick Guide
- **이벤트**: 오늘의 행사, 건물별 행사 수와 목록, 호실 색상 강조, 야외 아이콘, 메모 형태의 상세 안내
- **이벤트 검색**: 제목·설명·장소 검색, 부분 일치·띄어쓰기·간단한 오타를 반영한 유사도 정렬
- **이벤트 편집**: 패널 하단 편집 버튼으로 등록·수정·삭제, 야외 아이콘 드래그와 크기 조정
- **날짜 관리**: 한국 시간 기준 행사 당일에만 표시하고 자정에 자동 갱신
- **안내 패널**: 경계 중앙 버튼으로 접기·펼치기

이벤트는 현재 브라우저에만 저장됩니다. 다른 사용자와 공유하는 서버 저장소와 편집 권한 인증은 연결되어 있지 않습니다.

## 테스트

Node.js가 설치된 환경에서 실행합니다.

```bash
node campus-map/tests/event-rules.test.mjs
```

행사 날짜와 시간, 건물별 집계, 호실 일치, 아이콘 크기, 유사 검색을 검증합니다.
