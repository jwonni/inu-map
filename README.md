# inu-map

인천대학교 송도캠퍼스 층별 안내 지도. 건물을 누르면 층 선택기가 뜨고, 호실 배치가 건물 안에 바로 그려집니다.

앱은 [`campus-map/`](campus-map/) 폴더에 있습니다. `campus-map/index.html` 을 브라우저로 열면 서버 없이 실행됩니다.

- 사용법·파일 구성·건물 추가 방법: [campus-map/README.md](campus-map/README.md)
- 배치도 안내판 원본 사진: `campus-map/assets/signs/<건물id>/`
- 캠퍼스 지도 참고 자료(geojson, 지도 이미지): `campus-map/assets/reference/`
