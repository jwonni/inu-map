# 캠퍼스 한 걸음 · 인천대학교 송도캠퍼스

건물과 호실을 찾고 오늘의 행사를 확인하는 캠퍼스 안내 지도입니다. 아이보리 배경과 녹색 안내 패널, SVG 캠퍼스 지도, 층별 호실 배치를 사용합니다.

## 실행 방법

**`index.html`을 브라우저에서 열면 실행됩니다.** 별도 패키지 설치, 빌드, API 키는 필요하지 않습니다.

VS Code의 Live Server 또는 저장소 루트에서 `python3 -m http.server 8000`을 실행한 뒤 `http://localhost:8000/campus-map/`으로 접속해도 됩니다. 파일로 열었을 때와 로컬 서버로 열었을 때는 브라우저 저장 공간이 다를 수 있습니다.

## 지도 사용법

1. 지도에서 건물을 누르거나 왼쪽 **Quick Guide**에서 선택합니다. Quick Guide는 등록된 전체 건물을 호관 번호순으로 표시하며, 건물 데이터가 추가되면 자동으로 반영됩니다.
2. 지도 왼쪽 아래 층 선택기로 원하는 층을 엽니다. 선택한 층은 녹색으로 표시합니다.
3. 호실을 누르면 해당 호실을 강조하고 지도 왼쪽 위 카드에 호실·건물·층을 표시합니다.
4. 왼쪽 검색창에서 `7호관 403호`, `305`, `11호관 식당`, `도서관`처럼 검색할 수 있습니다.
5. 배경 드래그로 지도 이동, 마우스 휠 또는 `＋`·`－`로 확대·축소, `⟲`로 전체 지도를 봅니다.
6. 왼쪽 패널 경계 중앙의 화살표로 안내 패널을 접거나 펼칩니다.

입력 중이 아닐 때 방향키로 층을 바꾸고 `Esc`로 선택을 닫을 수 있습니다. 주소의 `#it/3F`와 같은 값은 건물·층을 지정합니다. 호실 데이터가 없는 건물이나 층에는 준비 중 안내가 표시됩니다.

## 이벤트 확인 및 검색

- 상단 **이벤트**에서 한국 시간 기준 오늘의 행사를 확인합니다.
- 건물 왼쪽 위 숫자는 해당 건물에 등록된 오늘의 행사 수입니다. 건물이나 숫자를 누르면 왼쪽 패널에 그 건물의 행사만 표시됩니다. **전체 보기**로 필터를 해제합니다.
- 실내 호실 행사는 별도 아이콘 없이 해당 층의 호실에 색을 입힙니다. 호실 또는 목록의 행사를 누르면 제목·설명·날짜·시간·장소가 메모 형태로 열립니다. 같은 호실에 여러 행사가 있으면 목록에서 선택합니다.
- 야외 행사는 부스·푸드트럭·설명회·공연·안내소·체험 아이콘으로 표시합니다.
- **오늘의 이벤트** 아래 작은 검색창에서 제목·설명·장소를 찾습니다. 부분 일치, 띄어쓰기 차이, 간단한 한글·영문 오타를 반영하고 유사한 결과를 위에 배치합니다. 검색을 시작하면 건물 필터를 해제합니다.
- 일반 이벤트 화면에는 호실 검색창이 없습니다. 실내 행사 위치를 편집할 때 다시 표시됩니다.

## 이벤트 등록·수정·삭제

1. **이벤트** → 왼쪽 패널 오른쪽 아래 **편집**을 누릅니다.
2. **건물 · 호실**에서 검색이나 지도 클릭으로 장소를 지정합니다. 건물 전체도 장소로 지정할 수 있습니다.
3. 야외 행사라면 **야외 아이콘**을 선택합니다. 아이콘을 지도에 끌어 놓거나, **지도에 위치 지정** 버튼을 누른 뒤 캠퍼스 안을 클릭합니다.
4. 배치 후에는 아이콘을 직접 드래그할 때만 아이콘이 이동합니다. 배경을 드래그하면 지도가 이동합니다. **다른 위치에 놓기**를 누르면 위치를 다시 지정할 수 있습니다.
5. 크기 슬라이더로 야외 아이콘 크기를 조정합니다. 범위는 화면 기준 12~36px, 기본 24px이며 지도를 확대해도 선택한 화면 크기를 유지합니다. 아이콘에 초점을 둔 상태의 방향키는 0.5, Shift 조합은 5 지도 단위로 미세 이동합니다.
6. 제목·설명·날짜를 입력합니다. **종일 행사**를 해제하면 시작·종료 시간을 입력할 수 있습니다. **이벤트 저장**으로 저장합니다.
7. **＋ 추가**로 계속 등록하거나 목록에서 기존 행사를 선택해 수정·삭제합니다. **편집 완료**로 일반 이벤트 화면에 돌아갑니다.

편집 화면에서는 과거·미래 행사도 관리합니다. 저장하지 않은 내용을 버리거나 페이지를 닫을 때 확인 메시지가 표시됩니다. 현재 편집 권한 인증은 적용하지 않아 누구나 이 브라우저의 이벤트를 편집할 수 있습니다.

## 날짜와 저장 기준

- 모든 시간은 **Asia/Seoul(한국 시간)** 기준입니다.
- 행사 당일 00:00부터 다음 날 00:00 직전까지 일반 이벤트 화면과 건물별 집계에 표시합니다. 내일 행사를 오늘 등록해도 오늘은 표시하지 않습니다.
- **시작 전 / 진행 중 / 종료 / 종일** 상태를 표시합니다. 오늘 종료된 행사는 당일 자정까지 확인할 수 있습니다.
- 자정 자동 갱신과 비활성 탭 복귀 시 갱신을 지원합니다. 자정을 넘는 행사는 날짜별로 나누어 등록합니다.
- 이벤트는 브라우저 `localStorage`의 `inu-campus-events-v1`에 저장합니다. 같은 브라우저·같은 주소에서 새로고침 후에도 유지됩니다.
- **다른 기기나 사용자와 이벤트를 공유하지 않습니다.** 브라우저 저장 데이터를 지우면 등록한 행사도 사라집니다. 공용 서버 저장소와 인증은 향후 연결 대상입니다.

## 파일 구성

```text
index.html                 기본 지도·이벤트 화면
app.js                     지도 이동·확대, 건물·층·호실 선택, 전체 Quick Guide
renderer.js                SVG 지도 및 실내 배치 렌더러
style.css / theme.css      지도·패널·편집 UI와 반응형 스타일
events.js                  행사 목록·검색·편집·아이콘·저장·자동 갱신
event-rules.js             날짜·입력 검증, 집계, 크기와 유사 검색
data/buildings.js          건물 이름·위치·크기·회전·층 목록
data/floorplans.js         층별 호실 배치 데이터
data/footprints.js         건물 윤곽
data/mapFeatures.js        지형·도로·운동시설
assets/events/             야외 행사 SVG 아이콘 6종
assets/signs/              건물별 배치도 안내판 원본
assets/reference/          지도 이미지와 GeoJSON 참고 자료
tests/event-rules.test.mjs  행사 규칙 및 검색 테스트
```

`assets/signs/`와 `assets/reference/`는 데이터 대조용 참고 자료입니다. 기본 지도는 원본 사진 대신 SVG로 렌더링합니다.

## 별도 지도·개발 페이지

기본 실행 파일은 `index.html`입니다. 저장소에는 별도로 개발한 다음 페이지도 포함됩니다.

- `inu-campus-map.html`: 위경도 기반 캠퍼스 지도와 길찾기, 실내 표시
- `it-detail.html`: 7호관 상세 지도
- `roads.html`: OSM 도로망 오버레이 확인용 페이지

이 페이지들은 기본 지도·이벤트 UI와 별개의 화면입니다. 온라인 지도 타일이나 외부 리소스를 사용하는 기능은 인터넷 연결이 필요합니다. `data/indoor-gen.js`, `data/entrances.js`, `data/it-osm.js`, `data/roadnet.js`는 해당 페이지의 데이터입니다. 실내 생성 데이터는 `node tools/build_indoor.mjs`로 갱신할 수 있습니다.

## 건물·호실 데이터 수정

1. `data/buildings.js`에 건물을 등록합니다. 기준 좌표는 962×841이고 `x`, `y`는 중심, `w`, `h`는 크기, `rot`은 회전각입니다. Quick Guide는 이 목록에서 자동 생성됩니다.
2. `data/floorplans.js`에 같은 건물 id로 층별 배치를 등록합니다. 지원 레이아웃은 `U`, `I`, `E`, `E2`입니다.
3. 계단·화장실·엘리베이터·빈 공간은 `#st`, `#wc`, `#ev`, `#_`로 지정합니다. 이름이 있는 공간과 자유 좌표의 호실·시설 배치도 지원합니다.
4. 원본 안내판은 `assets/signs/<건물id>/`에 보관합니다. 새 레이아웃이 필요하면 `renderer.js`의 `LAYOUTS`에 추가합니다.

## 테스트

별도 npm 패키지 설치 없이 Node.js로 실행합니다.

```bash
# 저장소 루트에서
node campus-map/tests/event-rules.test.mjs
```

현재 41개 검증으로 날짜 경계, 시간 상태, 위치, 건물별 집계, 층별 호실 일치, 아이콘 크기와 유사 검색을 확인합니다.
