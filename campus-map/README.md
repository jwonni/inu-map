# INU 캠퍼스 층별 안내 지도

인천대학교 송도캠퍼스를 카툰 스타일로 그린 지도입니다. 건물을 누르면 네이버 실내지도처럼 층 선택기가 뜨고, 그 층의 호실 배치가 건물 안에 바로 그려집니다.

서버 없이 `index.html`을 브라우저로 열면 바로 실행됩니다.

## 기능

- 카툰 지도: 지형·도로·운동시설은 `data/mapFeatures.js`, 건물 윤곽은 네이버 지도 캡처에서 자동 추출한 `data/footprints.js`
- 건물 클릭 → 오른쪽 층 선택기(위층이 위, 선택 층 파란색) → 호실이 건물 안에 렌더링
- 호실 클릭 시 강조, 검색창에서 건물 이름이나 호실 번호(`305`)로 검색
- 주소에 `#건물id/층` 이 남아 링크 공유 가능 (예: `index.html#it/3F`)
- 키보드: `←`/`→` 층 이동, `Esc` 닫기

## 호실 데이터가 있는 건물

| 건물 | id | 레이아웃 | 층 |
|---|---|---|---|
| 정보기술대학(7호관) | `it` | U자형 | B1, 1F~5F |
| 13호관 | `b13` | 일자형 | 1F~5F (B1은 번호 없음) |
| 14호관(경영대학·동북아) | `nea` | 일자형 | 1F~5F |

나머지 건물은 윤곽과 이름만 있습니다.

## 파일 구성

```
index.html          화면 뼈대
style.css           스타일 (층 선택기, 실내 레이어 색 등)
app.js              지도 확대/이동, 건물 선택, 층 전환, 검색
renderer.js         SVG 렌더러 + 레이아웃 생성기 (U자형 / 일자형)
data/buildings.js   건물 목록: 이름, 좌표, 크기, 회전, 층 목록
data/floorplans.js  층별 호실 배치 (배치도 안내판을 옮겨 적은 것)
data/footprints.js  건물 윤곽 다각형 (자동 추출)
data/mapFeatures.js 지형, 도로, 운동시설
assets/map.png      윤곽 추출에 쓴 원본 지도 캡처 (화면에는 쓰이지 않음)
assets/signs/       배치도 안내판 사진 원본
```

## 건물 추가하는 법

1. `data/buildings.js` 에 항목 추가. `x, y` 는 지도 좌표(962×841), `w, h` 는 건물 크기, `rot` 는 회전각.
   캠퍼스 격자는 `AX`(31°)와 `AY`(−59°) 두 방향입니다.
2. `data/floorplans.js` 에 같은 id 로 층별 호실을 적습니다.
   - **U자형** (`layout: 'U'`): `A_outer`, `A_inner`, `B_inner`, `B_outer`, `top_A`, `top_B`, `base`, `A_corner`, `B_corner`
   - **일자형** (`layout: 'I'`): `top`, `bottom` 을 왼쪽→오른쪽 순서로
   - 행 안에 `'#st'`(계단) `'#wc'`(화장실) `'#ev'`(엘리베이터) `'#_'`(빈 복도) 토큰을 섞어 쓸 수 있습니다.
   - `['109', '110']` 처럼 배열을 넣으면 한 칸을 둘로 나눕니다.
3. 새 건물 모양이 필요하면 `renderer.js` 의 `LAYOUTS` 에 생성기를 하나 추가합니다.

## 조정 포인트

- 클릭 시 확대 배율: `app.js` 의 `INDOOR_ZOOM`
- 색상 팔레트: `renderer.js` 의 `C`
- 건물 방향이 반대로 그려지면 해당 건물의 `rot` 에 180 을 더합니다.

## 지도 · 이벤트

`campus-walk` 스타일의 왼쪽 안내 패널과 지도입니다. 패널 경계 중앙의 화살표를 누르면 패널이 옆으로 접히거나 펼쳐집니다. 선택한 호실은 지도 왼쪽 위 안내 카드에 표시하며, 아래에는 층 선택기만 남깁니다.

### 이벤트 확인

- 상단 **이벤트**를 누르면 한국 시간 기준 오늘의 행사만 표시합니다.
- 건물 왼쪽 위 숫자는 그 건물에 등록된 오늘의 행사 수입니다. 건물이나 숫자를 누르면 왼쪽 패널에 해당 건물의 행사만 표시됩니다. **전체 보기**로 목록 필터를 해제합니다.
- 호실 행사는 별도의 아이콘 없이 해당 층의 호실을 색으로 강조합니다. 행사 목록이나 호실을 누르면 상세 메모가 열립니다. 여러 행사가 같은 호실에서 열리면 목록에서 선택합니다.
- 야외 행사는 작은 아이콘으로 표시합니다. 아이콘은 확대해도 화면에서 지나치게 커지지 않습니다.

일반 이벤트 화면에는 호실 검색 대신 **오늘의 이벤트** 아래 이벤트 검색창이 표시됩니다. 제목·설명·장소의 부분 일치, 띄어쓰기 차이, 간단한 한글·영문 오타를 처리하고 제목이 더 잘 맞는 결과부터 정렬합니다. 검색하면 건물 필터를 해제해 전체 행사에서 찾습니다. 호실 검색은 지도 화면과 실내 이벤트의 위치를 편집할 때 사용할 수 있습니다.

### 이벤트 등록 및 편집

1. **이벤트** → 왼쪽 패널 오른쪽 아래 **편집**을 누릅니다. 현재는 누구나 편집할 수 있습니다.
2. **건물 · 호실**에서 왼쪽 검색창이나 지도 클릭으로 장소를 지정합니다. 건물 전체도 장소로 지정할 수 있습니다.
3. **야외 아이콘**에서는 부스·푸드트럭·설명회·공연·안내소·체험 중 선택해 캠퍼스 안에 끌어 놓거나 클릭으로 배치합니다.
4. 야외 아이콘은 직접 드래그하거나 방향키로 위치를 조정하고 크기 슬라이더로 크기를 정합니다(12~36 화면 픽셀, 기본 24). 배경을 드래그하면 지도만 이동합니다. 위치를 다시 지정하려면 **다른 위치에 놓기**를 누른 뒤 지도에서 한 번 클릭합니다. 방향키는 0.5, Shift 조합은 5 지도 단위로 이동합니다.
5. 제목·설명·날짜와 필요하면 시작·종료 시간을 입력하고 **이벤트 저장**을 누릅니다.
6. 추가로 등록하려면 **＋ 추가**, 기존 내용을 수정·삭제하려면 목록에서 선택합니다. **편집 완료**로 일반 화면으로 돌아갑니다.

편집 화면에서는 과거·미래 행사도 관리할 수 있습니다. 저장하지 않은 내용을 버리거나 페이지를 닫을 때는 확인 메시지가 표시됩니다.

### 날짜와 저장

한국 시간(Asia/Seoul)의 행사 당일 00:00부터 23:59:59까지 표시합니다. 시작 전·진행 중·종료·종일 상태를 함께 보여주며, 오늘 종료된 행사도 당일 자정까지 목록과 건물 행사 수에 포함됩니다. 내일 행사는 오늘 일반 화면에 표시되지 않습니다. 자정 자동 갱신과 잠든 탭의 복귀 시 갱신을 지원합니다. 자정을 넘는 행사는 날짜별로 등록합니다.

이벤트는 `localStorage`의 `inu-campus-events-v1`에 저장됩니다. 같은 브라우저·같은 주소에서 유지되며 다른 사용자나 기기와 공유되지 않습니다. 기존 야외 아이콘 크기는 불러올 때 작은 범위로 맞춥니다. 인증과 공용 서버 저장소는 아직 연결하지 않았습니다.

- `events.js`: 이벤트 편집, 건물별 목록, 호실 색상, 야외 아이콘, 저장, 자동 갱신
- `event-rules.js`: 한국 시간, 건물별 행사 수, 호실 일치, 크기 및 입력 검증
- `assets/events/*.svg`: 야외 아이콘 6종
- `theme.css`: 화면 스타일, 패널 슬라이드, 반응형 배치
- `tests/event-rules.test.mjs`: 날짜·시간 경계, 위치, 건물별 집계, 층별 호실 일치 및 아이콘 크기 검증

Node.js가 설치된 환경에서는 `node tests/event-rules.test.mjs`로 테스트를 실행합니다.
